# Three.js Hex Map System — Roadmap

## Обзор

Новая система рендеринга гексовой карты на Three.js с поддержкой:
- Многоэтажности (elevation layers)
- Изолиний (contour-based height maps)
- GPU-ускоренного рендеринга
- Продвинутых визуальных эффектов

**Подход:** Hexes-First — данные остаются гексовыми, Three.js только для рендера.

## Технические заметки

### Структура данных гекса (v2)
```javascript
{
  q: 5, 
  r: 3,
  layers: [
    { 
      elevation: -1, 
      terrainId: 'water',
      opacity: 0.7 
    },
    { 
      elevation: 0, 
      terrainId: 'sand' 
    },
    { 
      elevation: 2, 
      terrainId: 'bridge',
      connectors: [{ type: 'stairs', targetLayer: 0 }]
    }
  ],
  objects: [
    { id: 'tree_oak', position: { x: 0.2, y: 0.1 }, rotation: 45 }
  ]
}
```

### Структура контура (Contour)
```javascript
{
  id: 'hill_1',
  layerId: 'ground',
  height: 3,
  points: [[x1,y1], [x2,y2], ...], // polygon
  interpolation: 'smooth', // smooth | cliff
  parent: null // вложенность
}
```

### Fallback стратегия
- Если WebGL недоступен → Canvas 2D рендерер
- Старый Asset Manager остаётся рабочим
- Данные конвертируются между форматами

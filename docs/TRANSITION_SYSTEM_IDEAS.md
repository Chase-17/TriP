# Transition System - Идеи и планы

## Текущее состояние (декабрь 2024)

Работающая система:
- CPU polyline deformation + GPU SDF rendering
- Line effects: subdivide, smooth, straighten, wave, noise, jagged, sine, zigzag
- Mask effects: gradient, scatter, noiseBlend
- Draw effects: shadow, glow, stroke
- Incremental caching для быстрого обновления

## 3. Расширение масок (приоритет: средний)

### Текущие
- **Gradient** - плавный переход
- **Scatter** - шумовое рассеивание
- **NoiseBlend** - градиент + шум

### Новые идеи
- **Voronoi edge** - граница по ячейкам Voronoi (лёд, каменные плиты)
- **Waves / Ripples** - волнообразная граница (прибой, лава)
- **Fingers / Tendrils** - "щупальца" проникают в соседний террейн
- **Erosion** - направленное "съедание" одного террейна другим
- **Dither / Stipple** - пиксельное смешивание (ретро-стиль)

### Композиция масок
- Применять несколько масок последовательно
- Режимы комбинирования: multiply, add, max, overlay
- Пример: scatter → gradient smoothing

- [ ] После scatter - тень от рассыпчатых краёв

```glsl
float edge = noiseValue - threshold;
if (edge > 0) {
  terrain = A;
} else if (edge > -shadowWidth) {
  // Зона тени
  terrain = B * (1.0 - shadowStrength * (1.0 + edge/shadowWidth));
} else {
  terrain = B;
}
```

## 5. Анимация (приоритет: средний)

### Глобальные тики
```javascript
uniform vec4 uAnimTicks; // 4 независимых фазы
// tick1: медленная волна (speed: 1.0)
// tick2: средняя (speed: 2.5)
// tick3: очень медленная (speed: 0.3)
// tick4: быстрая для бликов (speed: 5.0)
```

### Анимация слоёв террейна
```javascript
layer: {
  noise: 'simplex',
  animation: {
    offsetX: { tick: 1, amplitude: 0.02 },
    offsetY: { tick: 1, amplitude: 0.01 },
    scale: { tick: 2, amplitude: 0.05 },
  }
}
```

### Примеры применения
- Трава: лёгкое покачивание (offset слоя)
- Вода: движущиеся волны, блики
- Лава: пульсация яркости
- Снег: мерцание

## 6. Продвинутые идеи (приоритет: низкий/исследование)

### Height-based transition
- Heightmap террейна в шейдере
- "Вода заполняет низины"
- "Снег на вершинах"

### Weathering / Aging
- Параметр "возраста" границы
- Свежая = чёткая
- Старая = размытая, с мхом

### Biome influence
- Террейн влияет на соседей
- Лес + вода = болото на границе
- Песок + трава = сухая трава

### Seasonal layers
- Сезонные вариации террейнов
- Трава: зелёная/жёлтая/заснеженная

### Inside decorations
- Декор внутри патча зависит от соседей
- Опушка леса vs глубина леса

## 7. Архитектура (рефактор)

### Pipeline-based правила
```javascript
TransitionRule = {
  match: { from, to, level },
  pipeline: [
    { type: 'scatter', noise: 'perlin', scale: 0.1, threshold: 0.5 },
    { type: 'gradient', width: 0.3, curve: 'smooth' },
    { type: 'shadow', offset: [0.02, 0.02], blur: 0.1 },
  ],
}
```

### Разделение ответственности
- **Boundary effects** - изменяют форму границы (CPU)
- **Blend effects** - как смешиваются террейны (GPU)
- **Decoration effects** - что рисуется поверх (GPU)

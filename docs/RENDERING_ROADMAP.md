## 📝 Заметки

### Текущая архитектура рендеринга

```
1. groupHexesIntoPatches() — группировка по террейну
2. Сортировка патчей по elevation (низкие первыми)
3. Для каждого патча:
   a. buildExtendedPatchOutline() — backdrop для нижних слоёв
   b. buildPatchOutlineWithFade() — контур + fade segments
   c. smoothBoundaryLine() — Chaikin или Laplacian
   d. deformLine() — волны, рваность и т.д.
   e. drawPatchWithFade() — рендер с blur-based alpha mask
```

### Маска и альфа

Canvas 2D использует альфа-канал для композитинга, а не яркость.
Поэтому чёрно-белую маску нужно конвертировать:
- R/G/B → 255 (белый)
- A → исходная яркость (R)
